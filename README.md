# CSE370_Project
### Intro: <br> 
The project involves designing and implementing a basic Airline Management System. The system follows a role based access control approach, ensuring authorized access for different users such as administrators and passengers. Users can search for available flights, book tickets, track flights and track luggages through a centralized platform. To enhance experience, the system includes real-time delay notification feature to inform passengers about delayed flights. Additionally, a dynamic pricing system is implemented to simulate  real-world airline ticket price systems. The project aims to focus on practical application of database management and backend logic.<br>
### 
### Outro: <br>
This project provided significant insight on how the database system actually works. Key challenges included ensuring accurate database operations such as assigning foreign keys, selecting appropriate variable types, and managing database export and import. Additionally, developing a login-based booking system, handling bookings efficiently, ensuring security checks were quite challenging as well. Integrating the contributions of all group members also required substantial effort.  The key learning point of this project was the importance of database design and proper backend logic.The project facilitated the development of skills in backend development and database design and management. Further improvement of this project  could be more intuitive front end logic,implementation of dynamic pricing algorithms, a seat-locking system and more robust error handling to increase system efficiency and reliability.
